# Configurator — context voor Claude

Productconfigurator (configureren → prijzen → offerte) voor maatwerkmeubelen, eerste case: zitmeubelen voor een Belgische maker (vermoedelijke pilootklant Corneille & Silence, Harelbeke). Aparte app, koppelbaar met het ERP **Missing Link** (REST API met etag/If-Match en idempotency keys). Taal: **TypeScript**. De gebruiker (Jonas) is functioneel analist/implementator, geen programmeur: antwoord in het Nederlands, in gewone taal.

**Lees eerst `docs/overdracht.md`** voor de stand van zaken, links en open punten. Voor alles rond 3D, boven- en vooraanzicht: gebruik de skill `zetel-3d` (`.claude/skills/zetel-3d/SKILL.md`).

## Structuur
- `packages/core`: de motor (geen UI/ERP-afhankelijkheid). Formules als Excel-tekst → JsonLogic (`formule.ts`, `logica.ts`), productmodel (`types.ts`, `motor.ts`), modelcontrole, SVG-tekening (`svg.ts`), materialen, vrij ontwerp (`ontwerp.ts`: elementen, opties, vormgeving), vooraanzicht, 3D-opbouw (`ruimtelijk.ts`), zachte vormen voor de 3D (`zachtevorm.ts`, uitleg `docs/zachte-vormen.md`), doorlopende opbouw van een rij zitelementen als één zetel, ook in een boog (`doorlopend.ts`, Doha en Montego).
- `packages/core/voorbeelden`: demomodellen (kast, sofa per cm, zetelcatalogus `vrij-ontwerp.ts`, modellen `modellen.ts`). **Alle prijzen zijn verzonnen.** Proef met een echt 3D-bestand (4/11): `core/src/echt3d.ts`, `voorbeelden/proefmodellen.ts`, bestanden in `demo-web/modellen3d/` (het vreemde proefmodel Glam Velvet staat niet in de huisstijlversie; de negen eigen Blender-bestanden sinds 15/11 wel, akkoord Jonas); uitleg `docs/echte-3d-modellen.md`. Sinds 15/11 bouwen we zo'n bestand ook zelf met een script in Blender (`scripts/blender/`, lees eerst `scripts/blender/LEESMIJ.md`): negen fauteuils hebben er een (`voorbeelden/bestanden3d.ts`), de 3D toont het met de keuze *3D-bestand / Bouwstenen*. Blender is een werkplaats naast de configurator, geen deel van de bouw. Koppel een bestand alleen als het beter is dan de bouwstenen.
- `packages/demo-web`: klikbare demo, gebundeld met esbuild tot één HTML-bestand (`npm run build -w @configurator/demo-web` → `dist/configurator-demo.html`). three.js 0.187 (met de uitbreidingen voor nabewerking en `three-gpu-pathtracer` voor de fotomodus) zit mee in de bundel; er wordt niets van een CDN geladen.
- `packages/bouw-web`: aparte demo voor de bouwsector (ramen, deuren, aanbouw) op dezelfde motor, model in `core/voorbeelden/aanbouw.ts` + `aanbouw3d.ts` (`npm run build -w @configurator/bouw-web` → `dist/bouw-configurator.html` en `-offline.html`). ## Werkwijze
- Controles vóór elke commit: `npm test` (vitest) en `npm run typecheck` in de root. Bij een wijziging aan de ontwerper (toevoegen, kiezen, verwijderen, knoppen) ook `npm run ontwerper` (22 gevallen in een echte browser, ±1 min). Bij een wijziging aan de 3D (of wat erin komt) ook `npm run beelden` (beeldvergelijking, ±2 min, `beeldtest/LEESMIJ.md`); een bewuste wijziging vastleggen met `npm run beelden -- --vernieuw` en de nieuwe referentiebeelden mee committen.
- Code, namen en commentaar in het Nederlands, zoals de bestaande code.
- Branch: `claude/vigilant-cray-yi2j33` (enige branch in de repo, dus geen PR mogelijk).
- 3D lokaal testen: Chromium met `--use-angle=swiftshader --enable-unsafe-swiftshader` (zonder grafische kaart; kwaliteit *Mooi* is daar ±7 s per beeld, gebruik *Snel* of wacht lang). De 3D draait sinds 4/11 op `WebGPURenderer` (WebGPU, anders WebGL2): zonder extra vlag geeft Chromium in de cloud geen WebGPU en test je de WebGL2-terugval. Met `--enable-unsafe-webgpu` erbij is er wél een WebGPU-toestel in software (ontdekt op 14/11): onstabiel (het valt na een paar seconden weg), dus niet voor beelden, maar net goed om het herstel na een weggevallen toestel te testen. WebGPU voor het echte beeld blijft alleen op een echt toestel (de M5 in de toonzaal). Beelden nemen met `canvas.toDataURL()` (in de WebGL2-terugval met bewaard beeld) i.p.v. een elementscreenshot; in de app via `viewer.beeld()` of `foto()`. `window.__zetel3d` geeft in de ontwerper de 3D-weergave (bv. `fotoRealistisch({ stappen: 6, breedte: 520 })` voor een snelle proef van de fotomodus, ±2 min in swiftshader).
- Modellen van de klant niet verzinnen: wat uit foto's is afgeleid, markeren als benadering.
- De versie in de huisstijl van de klant (`configurator-corneille-silence.html`) alleen als bestand geven, niet publiek publiceren.
